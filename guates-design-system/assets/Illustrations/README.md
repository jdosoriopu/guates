# Illustrations

The ten hand-drawn line illustrations on a 200 × 200 canvas, each in the colour the brandbook shows it in. Single ink: in code use `<Illustration name color>` for any palette colour.

- `ilustracion-chiguiro.svg` — capybara holding a steaming cup. Cereza profunda.
- `ilustracion-mono.svg` — monkey holding a cup. Naranja tostión.
- `ilustracion-perezoso.svg` — sloth hugging a coffee bean. Verde moriche.
- `ilustracion-colibri.svg` — hummingbird at a flower. Verde moriche.
- `ilustracion-erizo.svg` — hedgehog. Cielo abierto.
- `ilustracion-garza.svg` — spoonbill (garza paletera). Sol de sabana.
- `ilustracion-nutria.svg` — otter floating with beans. Verde moriche.
- `ilustracion-pajaro.svg` — bird carrying a coffee branch. Atardecer llanero.
- `ilustracion-cafetera.svg` — espresso machine. Azul exploración.
- `ilustracion-granos.svg` — two coffee beans. Café de origen.
