# Logos

Official vector masters, cropped to the artwork. Each file is single ink; in code use `<Logo>` to set any approved colour.

- `guates-logo-principal.svg` — wordmark with *coffee Roasters* under the right half. Ink: Cereza profunda #81164B.
- `guates-logo-secundario.svg` — wordmark with the descriptor centred. Ink: Atardecer llanero #D6855A.
- `guates-logo-alternativo.svg` — wordmark alone. Ink: Azul exploración #4E71F0.

Protection area ¼ G on every side. Minimum 120 px tall (principal, secundario) and 48 px (alternativo) on screen.
