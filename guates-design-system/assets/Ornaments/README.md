# Ornaments

Brand marks copied from the brandbook and the 250 g label vectors.

- `estrella.svg` — the eight-point star of the chapter openers. Single ink: Sol de sabana here; strong palette colours only (`SectionMarker`).
- `grano-tostion.svg` — the outlined roast bean. Single ink: Café de origen here; set on labels in the label's ink (`RoastScale`).
- `sello-hecho-en-colombia.svg` — the circular seal. Three inks: ring Luz de mañana, centre and lettering Café de origen, beans Crema de papel (`Seal` recolours each).
