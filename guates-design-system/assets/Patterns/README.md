# Patterns

The three brand patterns on a 1920 × 1080 artboard, in official HEX values. In code use `<Pattern name>`, which binds every shape to a palette token.

- `patron-cruces.svg` — woven horizontal and vertical bands on crema (eleven palette colours).
- `patron-formas.svg` — organic discs and ellipses on crema.
- `patron-franjas.svg` — five rows of strong/light stripes: azul/cielo, moriche/brote, sol/luz, cereza/rosa, naranja/atardecer.
