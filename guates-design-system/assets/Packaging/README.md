# Packaging

Print-ready artwork from the studio, as PDFs.

- `bolsa-250g.pdf` — 250 g bag panels for Regional (crema), Lavado (cielo), Natural (brote), Honey (luz) and Platea (rosa): front, back and gussets.
- `bolsa-500g.pdf` — 500 g bag panels (Regional on café).
- `stickers-250g.pdf` — the five 250 g origin labels.
- `stickers-500g.pdf` — the 500 g label.
- `sticker-1kg.pdf` — the 1 kg label with logo, producer disc and the Regional band.

Text in these files is outlined. Editable Illustrator sources stay with the studio's asset kit.
