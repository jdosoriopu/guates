# Seal

The circular *Hecho en Colombia* seal from the labels: ring with the words twice, a dark centre with two beans.

**Props.** `size` (px, default 96), `ring` (default `luz-de-manana`), `ink` (centre and lettering, default `cafe-de-origen`), `bean` (default `crema-de-papel`). Inside an OriginLabel the ring takes the title colour and the centre the label colour.

**Use** on packaging, product pages and footers, at 64 px or more so the lettering survives. One seal per view.

**Don't** change its wording, rotate it, or set the ring and centre in the same colour.
