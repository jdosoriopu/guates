# Logo

The Guates wordmark, drawn from the official vector master, in any approved colour.

**Versions.** `principal` (wordmark with *coffee Roasters* bottom-right) is the default and the first touchpoint: packaging fronts, site header on first visit, presentations. `secundario` centres the descriptor. `alternativo` is the wordmark alone, for places where Guates is already introduced or the descriptor would be too small: social posts, merchandise, favicons-in-context, the vertical bag spine.

**Props.** `version`, `color` (a token name; default `ink`), or `on` (the background token, which picks the first logo colour the brandbook shows on it), `height` or `width` in px (height of the artwork; default is the digital minimum: 120 for principal and secundario, 48 for alternativo), `clearSpace` (adds the protection area, ¼ of the G, on all four sides), `title`.

**Do**
- Keep the protection area clear: no text, image, border or illustration inside ¼ G.
- Use only the pairs in `Guates.logoPairs` (or `on=`); on greys use `negro` from 0–50% and `blanco` from 60–100%.
- Switch to `alternativo` below 120 px tall.

**Don't** stretch, re-space, rotate, outline, shadow, gradient-fill or re-colour outside the palette; don't rebuild the wordmark in a font; don't remove the descriptor from `principal` by hand (use `alternativo`); don't set it on busy photography without a plain area behind it.
