# Illustration

One of the ten hand-drawn line illustrations (fauna, flora and coffee things), single ink, any palette colour.

**Names.** `chiguiro` (capybara with a steaming cup), `mono` (monkey holding a cup), `perezoso` (sloth hugging a bean), `colibri` (hummingbird at a flower), `erizo` (hedgehog), `garza` (spoonbill), `nutria` (otter with beans), `pajaro` (bird carrying a coffee branch), `cafetera` (espresso machine), `granos` (two coffee beans). The list is `Guates.illustrations`.

**Props.** `name`, `color` (token; default `ink`), `size` in px (square, default 160), `sticker` (a token: draws a rounded die-cut blob behind the drawing, as on the brandbook cover and the labels), `title` (gives it `role="img"`; omit for decorative use).

**Do**
- One colour per drawing. It does not need to be the animal's real colour.
- Keep enough contrast between the line and its ground for the stroke to read (aim for 3:1). Inside an OriginLabel the drawing uses the label's light partner colour.
- Let drawings bleed off an edge or overlap a frame, the way the bags and labels use them.

**Don't** fill the drawings, mix two colours in one drawing, distort proportions, or redraw them. For a new subject, commission it in the same hand.
