# SectionMarker

The chapter opener from the brandbook: a hand-cut star in a strong colour, a big Roboto Slab numeral and an uppercase title in that colour's light partner.

**Props.** `family` (the strong colour of the star: `sol-de-sabana`, `cereza-profunda`, `naranja-tostion`, `verde-moriche`, `azul-exploracion`, `cafe-de-origen`; default `naranja-tostion`), `number` (string, e.g. `"01"`), `title`, `color` (override the numeral and title colour), `size` (star height in px, default 96), `align` (`end`, the default, or `start`).

**Use** on photography or on a dark ColorBlock (`cafe-de-origen`, `verde-moriche`, `cereza-profunda`) to open a chapter of a deck, a long page or a campaign. The numerals are a sequence: only use them when the content really is ordered.

**Don't** set it on crema (the light partner colours disappear there), or use the star as a bullet.
